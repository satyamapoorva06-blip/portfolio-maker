# Contributing to Portify AI

First off, thank you for taking the time to contribute to Portify AI! 🎉

The following is a set of guidelines for contributing to Portify AI. These are mostly guidelines, not rules. Use your best judgment, and feel free to propose changes to this document in a pull request.

---

## Code of Conduct

This project and everyone participating in it is governed by the [Portify AI Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code.

---

## How Can I Contribute?

### Reporting Bugs

Bugs are tracked as [GitHub Issues](https://github.com/satyamapoorva06-blip/portfolio-maker/issues). Explain the problem and include information to help us understand and reproduce the issue:

* **Use a clear and descriptive title** for the issue to identify the problem.
* **Describe the exact steps which reproduce the problem** in as many details as necessary.
* **Provide specific examples** to demonstrate the steps (e.g. sample resume file type, browser version).
* **Include error logs or screenshots** if available.

### Requesting Features

Feature requests are tracked as [GitHub Issues](https://github.com/satyamapoorva06-blip/portfolio-maker/issues).

* **Use a clear and descriptive title** for the request.
* **Provide a step-by-step description of the suggested feature** in as many details as possible.
* **Explain why this feature would be useful** to developers using Portify AI.

---

## Pull Request Guidelines

1. **Fork the repo** and create your branch from `main`.
2. **Install dependencies**: `npm install`
3. **Verify Type Safety**: Run `npx tsc --noEmit` and ensure **0 errors**.
4. **Verify Production Build**: Run `npm run build` and ensure clean compilation.
5. **Issue a Pull Request** with a detailed explanation of your changes.

Thank you for contributing! 🚀
